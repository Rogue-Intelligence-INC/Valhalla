3. Fill out registration form
4. Verify email address
5. Login to EFS-Web portal

- `application_data_sheet_template.txt` - Fill in your information

1. Login to EFS-Web
2. Select "Provisional Patent Application"
3. Upload PDF files for each patent
4. Complete Application Data Sheet online
5. Submit payment information
6. Review and submit

## 🔧 **TROUBLESHOOTING**

### **If PDF Conversion Fails**
1. Copy text to Google Docs
2. Format properly (Times New Roman, 12pt)
3. Export as PDF
4. Or use Microsoft Word → Save as PDF

### **If EFS-Web Issues**
1. Try different browser (Chrome recommended)
2. Clear browser cache
3. Call USPTO help: (571) 272-1000
4. File by mail as backup option

### **If Payment Issues**
1. Use different credit card
2. Try bank transfer option
3. Contact bank to authorize USPTO charges
4. Use USPTO deposit account if available
