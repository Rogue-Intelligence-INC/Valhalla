## 执行摘要

Rogue Intelligence 交付 **Hybrid Valhalla hybrid-2.0** — 可部署的统一问答产品：每道题自动路由至原生结构记忆或补丁小语言模型。在 **fair-1.2** 去污染基准（145 题 test、配套 Qwen2.5-0.5B）上，统一产品 **总准确率 80.69%（117/145）**，开放题 **93.44%（57/61）**、多选题 **60.87%（28/46）**、数字题 **84.21%（32/38）** — 来源：`hybrid_v4_mcq_patch_strengthen_final.json`。

**我们销售**：可主权部署、可审计、结构可孵化的基础设施，以及 **可测量的 Hybrid 产品分数** — 而非「打败 GPT-4」。

**融资**：种子轮 **300–500 万美元** · 18 个月达成 3 个付费设计伙伴、MCQ 65%+、Hybrid SDK GA。

## 1. 市场机会

### 1.1 问题

| 痛点 | 市场信号（2025–2026） | Hybrid 回应 |
|------|----------------------|-------------|
| API 税与锁定 | 推理单位经济规模化后崩溃 | 本地 Rust 运行时 + 可选小 LM |
| 黑盒路由 | LangChain 隐藏内部状态 | 每答 `hybrid_source` 轨迹 |
| 垂直结构 | RAG  ephemeral；微调昂贵 | 一次孵化 → 持久 checkpoint |
| 数据主权 | 监管型本地 RFP | Tier B 无强制外部 API |
| Demo ≠ 产品 | 2026 投资人要求可运行产物 | fair-1.2 JSON + 公开 API v2.0 |

### 1.2 市场规模

| 层级 | 描述 | 规模 |
|------|------|------|
| **TAM** | 全球企业 AI 基础设施 + 私有 MLOps | $100B+ 品类 |
| **SAM** | 需本地可审计 Q&A 的监管 + 垂直 SaaS | 数十亿美元级 |
| **SOM（24 月）** | 3 设计伙伴 POC → Hybrid 授权 | **年收入 50–200 万美元** 路径 |

### 1.3 为什么是现在

- 资本从「概念 AI」转向 **可验证基础设施 + 单位经济**  
- **主权 + 推理成本** 成为采购硬条件  
- Hybrid **2.0 已交付**，公开可复现 — 非路线图 PPT

## 2. 产品与方案

### 2.1 Hybrid Valhalla 2.0（旗舰 SKU）

**一个路由器 · 全题型 · 2026 年 6 月产品定义**

| 题型 | 路由 | 测试准确率 |
|------|------|------------|
| 开放题 | 补丁 LM + 生成 | 93.44%（57/61） |
| 多选题 | 结构记忆 **或** 补丁 LM（deploy 路由） | 60.87%（28/46） |
| 数字题 | max(结构记忆, 补丁 LM) | 84.21%（32/38） |
| **总计** | 统一 | **80.69%（117/145）** |

### 2.2 产品矩阵（模块化）

| SKU | 描述 | 与 Hybrid 关系 |
|-----|------|----------------|
| **Hybrid Runtime** | 路由器 + 原生 QA + 补丁桥 | **旗舰** — 演示主体 |
| **Hub Enterprise** | 四象限路由 + Fate + 仪表盘 | 结构层 |
| **Tile / StemCell** | 结构生长引擎 | MCQ / 数字记忆 body |
| **孵化桥接（Tier A）** | 结构 → 补丁导出 | 开放 + 数字 patch 路径 |
| **原生 QA（Tier B）** | 无 HF 前向 | MCQ / 数字记忆路径 |
| **Wave + Val-OS + Yaksha** | 语言、OS、AEAD | 可选主权全栈 |

### 2.3 价值主张

```
闭源 API：   数据 → [黑盒 LLM] → 答案 → 永久 API 费
私有 LLM：   数据 → [自托管 LM + RAG] → GPU + 重训循环
Hybrid Valhalla：语料 → [孵化结构] → 路由器选记忆 OR 补丁 LM
                → 可审计轨迹 → 垂直迁移无需全量重训
```

### 2.4 协同叙事（已验证）

| 轨道 | 145Q test | 角色 |
|------|-----------|------|
| 仅 Qwen 0.5B | 103/145（71.03%） | 语言基线 |
| 仅结构记忆（tile+fate） | 59/145（40.69%） | 结构基线 |
| **Hybrid 统一** | **117/145（80.69%）** | **产品证明** |

Transformer 解决 **怎么说**；Valhalla 解决 **在什么结构上路由** 以及 **离线是否可审计**。

### 2.5 我们不销售的内容

- 相对前沿模型通用基准 SOTA  
- 「已替代 GPT-4」叙事  
- 无分题型的 MCQ 夸大宣传

## 5. 竞争分析

| 竞争者 | 类别 | 对方优势 | Hybrid 楔子 |
|--------|------|----------|-------------|
| OpenAI / Anthropic | 闭源 LLM API | 通用智能 | 主权、无 API 税、路由审计 |
| AWS Bedrock / Azure OpenAI | 托管 AI | 模型 SLA | 客户自有二进制 + checkpoint |
| LangChain / LlamaIndex | 编排 | 生态 | 原生孵化运行时，非套壳 |
| RAG + 微调栈 | 垂直适配 | 工作流熟悉 | 结构 checkpoint + hybrid 路由 |
| 纯本地 LLM（HF） | 本地推理 | 数据不出域 | 持久结构弱 |

**定位**：*可观测路由 + 自有基础设施 + fair test 80% 的 hybrid 协同。*
