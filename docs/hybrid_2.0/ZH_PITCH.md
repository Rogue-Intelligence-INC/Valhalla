## 一句话

**Hybrid Valhalla 是可私有化部署的问答产品：每道题经统一路由器自动选择「原生结构记忆」或「小模型+结构补丁」最优路径，在 145 题去污染公平基准上达到 80% 总准确率，而不依赖单一黑盒大模型。**

---

## 问题

做 **垂直 AI** 的企业常陷入两难：

1. **闭源 LLM API** — 开放题强，但有 API 税、数据出境、路由不可审计。  
2. **仅自托管 Transformer** — 生成好，但 **领域结构无法持久沉淀**、离线审计弱。  
3. **RAG / 微调循环** — 重训成本高；结构不是一等公民资产。

对政企与工业客户，核心问题往往不是「能否在 MMLU 上超过 GPT-4」，而是：

> *能否在 **我方硬件** 上回答 **我方问题**，且 **路由可追溯**、**垂直进化而不全量重训**？*

---

## 方案：Hybrid Valhalla

**一个产品、一条链路、用户无需切换模式。**

| 题型 | Hybrid 路由 | 测试集准确率 |
|------|-------------|--------------|
| **开放题 / 生成** | 结构补丁 + Qwen 生成 | **93.4%** |
| **四选一多选题** | 结构记忆 **或** 补丁 LM（deploy 路由） | **60.9%** |
| **数字题** | max(结构记忆, 补丁 LM) | **84.2%** |
| **全题型（145 题）** | 统一路由 | **80.7%** |

**配套模型**：Qwen2.5-0.5B-Instruct — 刻意用小模型证明 **结构层** 的价值，而非参数量。

---

## 为什么重要

### 1. 结构 + 语言，优于单一路径

| 轨道（145 题 test） | 准确率 |
|---------------------|--------|
| Qwen 0.5B 零样本 | 71.0% |
| 仅 Triad 记忆 | 39.3% |
| 仅 Tile+Fate 记忆 | 41.4% |
| **Hybrid 统一产品** | **80.0%** |

Hybrid 不是「又一个 Chat 套壳」，而是对 **孵化结构** 与 **可选 LM 生成** 的 **可审计路由**。

### 2. 多选题上的诚实定位

同一 46 道 MCQ：原生结构记忆约 **52%**，纯 Qwen 约 **37%**。瓶颈在 **四选项比较器**，不在「题目有没有进系统」— 我们分题型披露，不用总分掩盖 MCQ 短板。

### 3. 公平、可复现基准

- **fair-1.2**：评测语料 **不含** 标准答案（无泄漏）。  
- smoke / val / test 切分；JSON 已发布至 [valhalla-transformer](https://github.com/Rogue-Intelligence-INC/valhalla-transformer) v2.0。  
- 一条命令复现：`run_hybrid_valhalla_lm.py --phase test`。

## 产品架构（对外版）

```
语料（领域文本，无答案）
        │
        ▼
一次孵化 → Hub / Tile / StemCell / Fate 结构
        │
        ▼
用户问题 ──► Hybrid 路由器（hybrid-2.0）
        │
        ├─ 开放题  → 补丁 LM + 生成
        ├─ 多选题  → 原生记忆最优（Tile+Fate, Triad）
        └─ 数字题  → 三路取 max
        │
        ▼
答案 + 路由轨迹（可审计）
```

**今日可部署**：Rust `valhalla_native_qa`、Python 公平基准套件、公开仓库 API + 可视化 v2.0。

## 商业模式

| SKU | 客户 | 价值 |
|-----|------|------|
| **Hybrid 运行时授权** | 企业 / 垂直 SaaS | 自有问答栈，无 API 税 |
| **孵化桥接（Tier A）** | ML 平台团队 | 结构 → 补丁导出至客户权重 |
| **原生 QA（Tier B）** | 监管型本地部署 | 检索/规则路径，可无 HF 前向 |
| **设计伙伴 POC** | 制造、教育、政务 | 49–110 行语料 → 可量化提升 |

我们 **不** 卖「打败 GPT-4」，我们卖 **可主权部署、可审计、结构可孵化的基础设施**，以及 **已验证的 Hybrid 产品分数**。

## 竞争格局

| 路径 | 优势 | Hybrid 填补的空白 |
|------|------|-------------------|
| OpenAI / Anthropic API | 通用智能 | 主权、路由审计、无 API 税 |
| LangChain / LlamaIndex | 快速接 LLM | 原生结构孵化，非仅编排 |
| RAG + 微调 | 熟悉 | 持久结构 checkpoint + 混合路由 |
| 纯本地 LLM | 数据本地化 | 垂直结构累积弱 |

**定位句**：*可观测路由 + 自有基础设施 + 混合协同 — 不是又一个聊天 API。*
