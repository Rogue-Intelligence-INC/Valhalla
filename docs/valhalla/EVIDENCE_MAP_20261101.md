## E. 存档保真边界（2026-11-01 实测）

SAVE vs LOAD 指纹：tiles 1023、cells 1124、tile_edges 5100、stem_links 126532、
平均强度 3.573、存储 8192 条、方程 `0.6706x²−1.9066x+0.6179`、sig 8388611、disc 6790 —— 逐字一致。
不入档：monitor 累计（tile_merges 14→0、synapses_born 3067→0）、efficiency（0.0008→0.0000）。
解冻续训已验可用（解冻 8MB 身体续喂 2MB 正常收尾）。
新发现边界（2026-11-01 下午）：细胞 id 是计数器 `cell_{total_containers_closed}`，
存档计数与现存 id 上界脱节——解冻的 100MB 身体里 12,753 个细胞只有 12,656 个
唯一 id（97 例存量重复），续生新细胞继续撞旧 id。以 id 为键的下游统计
（出生计数、按 id 建邻接）在解冻身体上有 ~1% 级系统噪声；判断包结论不依赖
单点 id，但此后凡用 id 计量必须先声明此边界。
