# 修死亡判定 预注册（2026-11-02，用户定向）

## 背景与裁定

去硬编码全套结果：check 全过、L 保住（+22.0±2.8），
但身体塌缩约十倍（470/406）、遗忘加重（BWT −27.3pp）。
机制读法：check_diffs 的"典型"带在方程未适应期过窄，
低于均值者大批被判不典型而死，种群螺旋收缩。用户裁
定：保持全部去除，只修死亡判定形式。

## 修法（只动死亡，Stem/Tile 对称）

死亡由 `energy<avg 且 !check_diffs([energy, avg])` 改为：
`energy < avg 且 energy < avg × r`，其中 r 为本层簇方
程的小根（无实根时取顶点横坐标 −b/2a）——与场吸引/
排斥的中性点同一条代数界（Stem 复用 equation_neutral，
Tile 同式新增）。根在本周期判定前冻结（其后 check_diffs
的适应不影响本轮死亡线）。分裂判定、连接、场、出生、
传播全部保持去硬编码现状，一次只动一个变量。
无新写死常数：根由方程系数算出，随方程适应自行移动。
