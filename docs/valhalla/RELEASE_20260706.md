## 核心特性

### 1. Dynamic Corpus Fragments（统一功能）

`VALHALLA_DYNAMIC_CORPUS_FRAGMENTS=1`（默认，随 `FRAGMENT_MODE≠off`）

| 旧机制 | 新机制 |
|--------|--------|
| 只 ingest 最后 32 行 | **全行 ingest** 进 Fate density 片段 |
| `QUERY_FRAGMENT_MERGE` 独立开关 | **query merge 随 dynamic 开启** |
| top_k=3 固定，长 session 漏 needle | **top_k 随 corpus 放大** + **keyword anchor 保底** |

详见 [`MANIFOLD_FRAGMENT_V1.md`](./MANIFOLD_FRAGMENT_V1.md)

### 2. Fate 收敛驱动（Warmup + Adapt）

- **Prelearn + warmup** 后再 density 分段（`VALHALLA_FATE_WARMUP`）
- **Adapt / pulse 轮次** 由 Fate 收敛停止，非固定计数
- Env: `VALHALLA_FATE_WARMUP_*`, `VALHALLA_FATE_PULSE_*`

### 3. 3B 生产默认

| 项 | 默认 |
|----|------|
| LM | `Qwen/Qwen2.5-3B-Instruct` |
| GPU | CUDA on（`VALHALLA_USE_CPU=0`） |
| 配置 | `tools/valhalla_inference/benchmark_env.py` |

### 4. MCQ 缩放律（lm_patch）

同栈换 backbone：**0.5B 61% → 3B 98%**（46Q）  
`acc ≈ 0.752 + 0.475·log₁₀(B)` — 详见 [`MCQ_SCALING_POTENTIAL_20260706.md`](../../reports/valhalla_inference/MCQ_SCALING_POTENTIAL_20260706.md)

### 5. Benchmark 套件拆分

```bash
# 常规 industry（RAGTruth · LongBench · MCQ ladder …）
python3 tools/valhalla_inference/run_industry_benchmarks.py --all

# 稍后单独跑 AGI / 训练代理
python3 tools/valhalla_inference/run_industry_benchmarks.py --agi-only
```
