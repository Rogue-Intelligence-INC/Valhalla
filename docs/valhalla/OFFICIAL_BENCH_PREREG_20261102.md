# 官方基准投影跑 预先声明（2026-11-02，跑前落笔）

数据已下载至 `C:\Ai\official_bench\`（不入 git）：bAbI
tasks_1-20_v1-2（ParlAI 官方分发包）、CLUTRR EMNLP 论文
预生成集（Drive 官方链接，data_089907f8 系统泛化集）。
纪律先行：我们的通道（自形成结构上的可达/最短路 + 存储
逐字出口）不能生成答案串，故官方任务一律用**多选投影**
跑——身体图对候选排序、官方标注给真值——并在一切对外
表述中称"官方数据的多选投影"，**绝不称官方分数**。解析
只用于定位问题/候选对应的单位（与孵化证明的符号映射同
地位），排序信号必须出自身体图，不许用词面共现冒充。

## 一、bAbI（qa1 单支撑 / qa2 双支撑 / qa3 三支撑）

- 文件：`en/qa{1,2,3}_*_test.txt` 官方测试集；每题取文件
  前 200 个故事（行首编号 1 起的新故事），确定性前缀子集。
- 喂入：故事内每句一行条目，经 `feed`（ingest+promote）
  逐句喂入、每句后不周期、故事毕 2 周期；词→单位映射 =
  该词出现的句子出生单位之并（标点剥离、词形原样）。
- 问题：问题句中与故事词表相交的名词性词为查询实体（取
  首个大写词或与候选不交的已知实体词，按文件词表匹配，
  规则写死在运行器注释）；候选 = 该任务全部故事中出现过
  的答案词集合（由训练文件词表离线统计，跑前固定打印）。
- 打分：候选得分 = 查询实体单位到候选词单位的最短路
  （Stem+Tile 双图较小者，不可达记 999），取最小者为答；
  并列取候选表序最先。准确率对官方答案。
- 对照：chance = 1/候选数；G 臂 = 同身体 `shuffle_structure`
  后同法打分。**通过线（先写死）：C 准确率 > chance 且
  C > G（故事级配对均值），两条同过才记该任务投影通过。**

## 二、CLUTRR（k=2 子集，距离投影）

- 文件：`1.2_test.csv`（Python csv 预处理为 TSV：story
  句列、query 两名、proof 链长；脚本留档）。**跑前修正
  （2026-11-02，见数据后、打分前）**：1.2 实测仅 38 行，
  故改用 1.2 全量 38 行 + 1.3 全量 105 行（链长 2/3 两
  档），协议与通过线不变；本修正先于运行记录在此。
- 喂入与 bAbI 同（story 字段逐句）。读数：查询两名单位
  间最短路 vs proof 真链长：报 (i) 真对 reach@5 率；
  (ii) |身体路长 − 真链长| 均值；(iii) 同读数在 G 臂
  （shuffle 后）的值。**通过线：C 的 (ii) 小于 G 的 (ii)
  且 C reach@5 > G reach@5，记距离投影成立**；关系标签
  分类（官方原任务）不测、明确写未测。
