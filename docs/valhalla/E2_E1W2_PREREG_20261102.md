# E2 原生闭环答题 + E1W2 判别尺 预先声明（2026-11-02，跑前落笔）

本文件在两项实验运行之前写定并提交。判据先于数据；跑完只
许照判据判读，不许改尺子、挑种子、挑题量。两项都只用身体
既有机制（Tile/Stem/Fate 自有入口与周期），不建平行系统，
不把问题喂给内部 Fate 做训练。

## 一、E2：刺激经身体自有入口进入后，身体能否自定位

背景：D10/D11 的失败谱系——历次问答都没有"刺激→内部组织
→取料"通路；出口读数曾被周期自身节目主导（v1 三臂回应前
12 名重叠 12/12），当时记下的缺失件是"刺激臂−静默臂差分
未做"。A13 另测得 Stem 层位置扰动 Σ‖Δpos‖ 随材料变、对微
扰稳、对序列敏感。本实验把这两件合起来做构造效度内的最
小闭环：刺激只经身体入口（feed 的 ingest+promote 路）进
入，身体自跑一个周期，读出既有细胞的差分位移，看响应是
否富集在刺激所属链的单位上。计分真值由培养构造给出（链
归属），不由外部裁判给；符号映射只用于计分标注，不参与
产生响应（与图上 BFS 答题的根本区别：那里映射直接构造答
案路径，这里身体若无响应即测不到）。

协议（每种子）：
- 身体与主证明 C 臂同构：`cultivate` 3 阶段（200 符号池）
  + 12 条完整测试链单环事实经 `feed_tracked` 喂入 + 1 周期，
  完整存档为冻结基线。
- 题目：12 链 × (chain[0]→chain[3]、chain[0]→chain[5])
  = 24 题。两种问法（换问法臂）：F1 `A>B`（训练条目原格式
  字节）；F2 `A > B`（加空格的表面变体，字节不同、所指同）。
- 每题每问法两臂，均从同一冻结存档 `load_full`（起点逐字
  相同）：刺激臂 = 快照 Stem 细胞位置 → `feed(刺激)` → 1 个
  `cycle()` → 逐细胞 ‖Δpos‖；静默臂 = 快照 → 直接 1 个
  `cycle()` → ‖Δpos‖。差分响应 r_i = max(‖Δpos‖_刺激 −
  ‖Δpos‖_静默, 0)，只计冻结时已存在且周期后仍存活的细胞
  （刺激新生细胞、周期内分裂新生细胞不计分）。
- 定位真值集 T(A) = A 所属链全部符号在测试喂入时出生的
  Stem 细胞（与冻结存活集取交）。富集度
  E = (Σ_{i∈T} r_i / Σ_all r_i) / (|T| / N)，E=1 为机会水
  平；Σ_all r_i = 0 时该题记 E=1（无响应即机会，不奖不罚，
  另计无响应题数）。
- 种子级：两问法各自 24 题 E 的均值。

预先声明判据：**E2 成立 ⟺ 15 种子中 ≥12 个种子两问法均值
同时 > 1，且两问法各种子均值的总均值都 ≥ 1.3。** 任一问
法不过即该问法未检出；整体不过记"E2 未检出"并注明倒在哪
臂。只报告不计判据：跨链对照刺激（A 链外配对，T 仍取 A
链）、题级 E>1 占比、无响应题数、刺激新生细胞周期后最近
既有邻居的链归属、Tile 层不读（D12 三代仪器全盲在案，本
轮不重复投入）。

预期与边界（先写明，防事后叙事）：若成立，只证"刺激能经
入口在自有动力学里定位到相关组织"这一自定位环节，不证
完整问答（取料与作答未测）；若败于 F2 而过 F1，结论是表
面形式敏感、语义定位未立。

## 二、E1W2：宽度判别尺（E1W 的下一轮，非重判）

背景：E1W（种子 1–15）联合判据未过（均路臂 0/15，见
EVIDENCE_MAP D13 与 TEST_RUNS）；其记录中已写明下一轮候
选尺子须运行前另行声明。均路在构造上偏爱展开图，故本轮
主尺子换为判别量。**本轮数据与 E1W 不重叠：种子 16–30**
（培养/题目/三臂构建与 `width_seed` 同代码路径，不改）。

主尺子（唯一计判据）：固定预算 5（=NET_BUDGET）下
Δ = 真题可达% − 硬假可达%，硬假可达% = 100 − 硬假拒绝%。
逐种子对 C-宽、C-同、H严（C-宽严格双边交换重连）各算 Δ。

预先声明判据：**E1W2 成立 ⟺ (a) 逐种子 Δ（宽−同）> 0 的
种子 ≥12/15 且其均值 > 0；(b) 逐种子 Δ（宽−H严）> 0 的种
子 ≥12/15。** 两条同过才记"宽度使拓扑判别成立"（D13 相
应修订）；只过 (a) 记"宽度效应存在但未胜零模型"，主张维
持未检出；(a) 不过记宽度判别未检出。只报告不计判据：各
臂真/硬假/易假/均路四读数（与 E1W 同格式）、Δ 的题级构成。

与旧数据的关系（防回溯声明）：尺子候选在 E1W 记录中已
先行写明（TEST_RUNS 维度修复节），但 E1W 的逐种子数据已
被看过，故本轮一律用新种子；E1W 数据只作背景，不进入本
轮判读统计。
