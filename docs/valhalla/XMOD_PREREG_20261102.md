# XMOD 跨模态链回答 预先声明（2026-11-02，跑前落笔）

动机（用户指出）：现行训练与问答只在文本符号链上作答，
自然料（图/声/码）只喂不答——"多模态回答"未体现。本实验
构造效度内的最小跨模态版：链的节点是四种模态的真实字节
片，链条跨模态连接，看自形成结构能否像文本链一样支撑多
跳回答。判据先于数据，仍只用身体既有机制。

## 协议（VH_XMOD=1，每种子）

- 模态 4：文本（红楼梦）、代码（stemcell_complete.rs）、
  图片（Windows 壁纸 jpg）、声音（Alarm01.wav）。令牌 =
  各语料确定偏移处的 40 字节切片（种子决定偏移）。
- 48 条链 × 6 令牌；链内每个位置的模态按 文→图→声→码
  循环（每条链相位随种子移位），故相邻关系多为跨模态。
  条目 = tokA ‖ ">" ‖ tokB（相邻对），出生单位按喂入调用
  归属两端令牌（不解析字节内容，防补丁内含 '>' 误标）。
- 训练（少量多喂排程）：6 轮 ×（全部相邻对条目打乱喂入
  + 2 周期）。三臂同令牌同条数：C 链结构；A 随机配对
  （无链）；G = C 后 `ablate_structure`（拆边存字节）。
- 题目：链内 dist 2..5 真题（多跳，须跨模态传递）、跨链
  假题；统一预算 5（NET_BUDGET），Stem+Tile 双图取可达。
  计分映射只作标注，不构造答案路径（同主证明纪律）。

## 预先声明判据

**XMOD 成立 ⟺ 15 种子中 ≥12 个种子 C 真题可达同时 > A
且 > G（逐种子配对）。** 不过记未检出，注明倒在哪臂。
只报告不计判据：假题误答率、各臂均值、逐模态跨越构成

构承重"这一结构命题，不证语义层面的多模态理解（令牌是
字节片、无语义标注）；败则多模态回答在本机制下未立，
