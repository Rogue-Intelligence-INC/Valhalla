|------|------|--------|----------|
| **可逆性** | Dec(Enc(P, K), K) = P | 100% | 全量测试 |

## 2. Basic 版本测试结果

### 2.1 版本规格

| 参数 | 值 |
|------|-----|
| 维度 | 2.20 (固定) |
| dim_factor | 156 |
| frac_factor | 46 |
| Cascade 初始值 | key[0] + dim_factor |

### 2.2 可逆性测试

| 测试用例 | 数据大小 | Vector | Entropy |
|---------|---------|--------|---------|
| ASCII 字符串 | 13 B | 100% ✓ | 100% ✓ |
| 全字节 0-255 | 256 B | 100% ✓ | 100% ✓ |
| 全零 | 1000 B | 100% ✓ | 100% ✓ |
| 全 0xFF | 1000 B | 100% ✓ | 100% ✓ |
| 伪随机 | 10000 B | 100% ✓ | 100% ✓ |

**结论**: 两种模式均实现 100% 可逆性。

### 2.3 雪崩效应测试

| 模式 | 测量值 | 与理想值偏差 | 评级 |
|------|--------|-------------|------|
| Vector | 48.76% | -1.24% | 优秀 |
| Entropy | 51.58% | +1.58% | 优秀 |

### 2.4 统计学测试

| 指标 | Vector | Entropy | 理想值 |
|------|--------|---------|--------|
| 香农熵 | 7.96 bits/byte | 7.95 bits/byte | 8.0 |
| χ² 统计量 | 268.4 | 271.2 | ~255 |
| 位偏差 (max) | 2.31% | 2.58% | 0% |

### 2.5 安全性分析

**发现的问题**:

1. **前缀泄露 (已确认)**
   - 相同前缀明文 → 相同前缀密文
   - Cascade 只向前传播，不向后传播
   - 缓解因素: 维度作为秘密参数，攻击者无法解密内容

2. **确定性加密**
   - 同密钥同明文 → 同密文
   - 无 Nonce/IV 机制

3. **ARX 轮数**
   - Vector 模式仅 2 轮
   - 低于行业标准 (AES: 10-14, ChaCha: 20)

## 5. 已知限制与建议

### 5.1 当前限制

1. **无 Nonce/IV**: 确定性加密，不适合需要语义安全的场景
2. **前缀泄露**: Cascade 单向传播
3. **ARX 轮数不足**: 可能存在差分攻击路径
4. **无密钥调度**: 直接使用密钥字节

### 5.2 缓解措施

1. **维度作为秘密**: 未知维度情况下，前缀泄露不导致解密
2. **组合使用**: 可与其他加密层组合使用
3. **内部场景**: 适合 Valhalla 内部数据保护

### 5.3 未来改进方向

1. 引入 Nonce/IV 机制
2. 增加 ARX 轮数
3. 实现双向 Cascade
4. 添加密钥扩展函数

## 6. 结论

Val-Crypt 实现了以下目标：
- ✓ 100% 可逆对称加密
- ✓ 理想雪崩效应 (~50%)
- ✓ 高吞吐量 (>275 MB/s)
- ✓ 动态维度扩展密钥空间

对于 Valhalla 内部使用场景，当前安全性足够。不建议用于需要抵抗高级攻击的外部通信加密。
